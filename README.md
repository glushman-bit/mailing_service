# Mailing Service (Сервис управления рассылками)

Веб-приложение на Django для создания, настройки и автоматизации email-рассылок. Проект ориентирован на высокую производительность, конфиденциальность пользовательских данных и содержит встроенный аналитический дашборд для отслеживания статистики в реальном времени.


## 🚀 Ключевые особенности и архитектура

*   **Конфиденциальная отправка (Скрытые получатели):** Рассылка отправляется каждому клиенту персонально в изолированном цикле. Получатели писем никогда не увидят email-адреса других участников рассылки.
*   **Высокопроизводительный Batch-логинг:** Запись результатов отправки (`MailingAttempt`) выполняется единым пакетом с помощью метода `bulk_create` (технология пакетной обработки данных).
*   **Умный сквозной дашборд:** На главной странице реализован точный подсчет метрик (соотношение запусков рассылок и отправленных сообщений). Система корректно обрабатывает частично успешные сессии и не дублирует исторические данные благодаря фильтрации по уникальным маркерам запусков (`run_id`).
*   **Двухуровневое кэширование:**
    *   *Серверное (Низкоуровневое):* Кэширование тяжелых QuerySet-запросов и целых страниц с помощью Redis. Кэш изолирован для каждого пользователя.
    *   *Клиентское (Браузерное):* Оптимизация отдачи статики и динамических страниц с помощью HTTP-заголовков `Cache-Control` (параметр `private=True`), предотвращающая повторную загрузку данных браузером.
*   **Автоматизация управления:** Наличие кастомных Django-команд для быстрого развертывания структуры прав и ролей доступа без участия веб-интерфейса администратора.

---

## 🛠 Технологический стек

*   **Backend:** Python 3.10+, Django 6 (Class-Based Views, Django ORM)
*   **Database:** PostgreSQL (с полной поддержкой сложных агрегаций и `distinct()`)
*   **Кэширование:** Redis
*   **Качество кода (Линтеры):** Black, Flake8 (конфигурация через `pyproject.toml`)

## 📦 Установка и запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/glushman-bit/mailing_service.git
```


### 2. Настройка окружения

Создайте файл `.env` в корневой директории проекта и заполните его по образцу файла `.env.example`


### 3. Установка зависимостей и миграции
```bash
# Установите зависимости (если используется Poetry или виртуальное окружение)
pip install -r requirements.txt

# Выполните миграции базы данных
python manage.py makemigrations
python manage.py migrate
```

```bash
# Для предварительного заполнения БД используйте фикстуры
# Для пользователей
python manage.py loaddata users_fixture.json

# Для Получателей рассылки, Сообщений, Рассылок и Попыток рассылок
python manage.py loaddata mailing_service_fixture.json
```


### 4. Инициализация ролей доступа (Кастомная команда)

Для автоматического создания superuser, запустите встроенную утилиту:
```bash
python manage.py create_superuser
```

Для автоматического создания группы «Менеджеры» со всеми необходимыми системными и кастомными правами доступа, запустите встроенную утилиту:
```bash
python manage.py create_managers_group
```

### 5. Запуск сервера разработки
```bash
python manage.py runserver
```
Приложение будет доступно локально по адресу: `http://127.0.0`

## 📊 Структура хранения логов (`MailingAttempt`)

Каждая строка лога привязана к ManyToOne-связи с рассылкой и содержит:
*   `status` (`success` / `failure`) — статус доставки конкретного письма.
*   `server_response` — детальный лог ответа SMTP-сервера или текст ошибки.
*   `run_id` — уникальный строковый UUID-маркер, объединяющий всю пачку писем из одного пакетного (`batch`) запуска в единую сессию для корректного аналитического подсчета.
